# Projeto G2 — Gerenciador de Tarefas Acadêmicas

## Equipe
- Arthur Rodrigues
- Rebeca Alencar
- Vitor Cabral

## Framework
Angular com TypeScript.

## Pré-requisitos
- Node.js em versão compatível com o projeto
- npm

## Instalação
```bash
npm install
```

## Executar o frontend
```bash
npm run dev
```

## Executar a API local
```bash
npm run api
```

## Endpoints da API
- GET http://localhost:3000/tarefas
- GET http://localhost:3000/projetos
